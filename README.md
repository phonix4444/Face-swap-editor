# AI Face Swap Video Editor Studio
A professional, modern AI-powered Face Swap Video Editor web application built with **Streamlit**, **OpenCV**, and **Python**.

## 🚀 Features
* **Face Upload:** Upload target face images (JPG, PNG, WebP).
* **Video Upload:** Import videos in MP4, MOV, AVI formats.
* **AI Face Detection & Swapping:** Automatic facial landmark tracking, expression matching, and neural lighting harmonization.
* **Timeline Editor:** Frame navigation, trimming, and color grading.
* **Project & Export Management:** Track projects and download high-resolution exported videos.
* **Professional Dark UI:** Sleek modern interface tailored for video editing studios.

## 🌐 How to Deploy Globally on Streamlit Community Cloud

Follow these simple steps to host this application for free on the global web via Streamlit Cloud:

### Step 1: Push your code to GitHub
1. Create a new repository on [GitHub](https://github.com/new) (e.g., `ai-face-swap-editor`).
2. Initialize git and push your project files (`app.py`, `requirements.txt`, `README.md`) to your GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for AI Face Swap Studio"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
   git push -u origin main
   ```

### Step 2: Deploy on Streamlit Cloud
1. Go to [share.streamlit.io](https://share.streamlit.io/) and sign in with your GitHub account.
2. Click **New app**.
3. Select your GitHub repository, branch (`main`), and set the main file path to `app.py`.
4. Click **Deploy!**

Your AI Face Swap Video Editor will be live globally with a shareable URL in less than 2 minutes!
